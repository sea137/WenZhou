# 海京·文舟 | WenZhou

**把故事写下来，也把喜欢的书读进去。**

免费的 Windows 本地小说创作、小说阅读与漫画管理软件。目前为 **0.23.0 Beta 2** 测试版。

## 下载

👉 **[前往 Releases 下载 Windows 安装包](https://github.com/sea137/WenZhou/releases)**

普通用户请选择 `wenzhou-0.23.0-beta.2-windows-x64-setup.exe`。无需另装 Node.js 或 Python。

开发者或需要对应源码的用户，请下载同一 Release 的 **`wenzhou-0.23.0-beta.2-source.zip`**。GitHub 自动生成的 “Source code” 压缩包只包含本分发仓库的说明文件，完整对应源码以手动附加的 source.zip 为准。

## 可以做什么

- **写小说**：章节与卷管理、大纲、人物及世界设定、人物关系网、灵感笔记、版本历史与备份。
- **读小说**：滚动、单页、双页与沉浸阅读，书签、彩色标记、批注、圈画与批注导出。
- **看漫画**：PDF、EPUB、标准 MOBI 6/AZW、CBZ、ZIP、图片目录，系列选册、分册续读、旋转与缩放。
- **按习惯调整**：主题、本机字体、界面缩放、侧栏宽度、自定义快捷键。
- **可选 AI 辅助**：自行配置模型 API，预览并决定是否采纳建议。手动写作和本地阅读无需配置模型。

## 导入说明

| 内容 | 入口与支持范围 |
|---|---|
| 小说 | “导入小说”，TXT / Markdown / EPUB / DOCX / HTML，单个文件最大100 MB |
| 漫画单册 | “漫画藏书 → 导入漫画文件”，PDF / EPUB / MOBI 6 / AZW / CBZ / ZIP |
| 漫画系列 | “导入漫画目录”，识别各册并分别保存阅读位置 |
| 漫画图片 | JPG / PNG / WebP / GIF / BMP 图片目录 |

单册EPUB/MOBI漫画最大512 MB，每个漫画记录最多10000页；默认文字目录，缩略图按需加载。KF8/AZW3、HUFF/CDIC压缩MOBI、受保护电子书暂不支持，可先转换为支持的格式。复杂SVG合成页面可能无法完整还原。

## 资料与反馈

作品和阅读记录保存在本机，安装包不包含个人书稿、账号密钥、测试小说或漫画全文。开启AI功能时，所选文本与配置的上下文会发送到你指定的模型服务；相关API费用由服务商决定。

这是Beta测试版，使用前及升级前建议备份作品。遇到问题可到 **[Issues](https://github.com/sea137/WenZhou/issues)** 提交：软件版本、操作步骤、期望结果、实际结果及截图；导入问题请附文件格式和大小。请勿公开提交密钥、私人书稿或无权分发的完整书籍。
